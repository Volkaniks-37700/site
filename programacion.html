Programación FTC para Java

Esta guía está diseñada para quien ya tiene bases de Java y programación orientada a objetos. Aquí encontrarás los conceptos específicos de FTC, ejemplos de código y la ruta para dominar el autónomo y las trayectorias.

01

Estructura de un Op Mode

Todo programa en FTC hereda de LinearOpMode o OpMode. Aquí usamos LinearOpMode.

📦

Esqueleto básico

@TeleOp(name = "MiTeleOp") public class MiTeleOp extends LinearOpMode { @Override public void runOpMode() { // Inicialización waitForStart(); while (opModeIsActive()) { // Loop principal } } }
🔑

Métodos clave

  • runOpMode() — Punto de entrada.
  • waitForStart() — Espera a que el driver presione START.
  • opModeIsActive() — Verdadero mientras el Op Mode corre.
  • telemetry.addData() — Envía datos a la Driver Station.
  • telemetry.update() — Refresca la telemetría.
  • sleep(ms) — Pausa la ejecución.
02

Control con Gamepad

Los gamepads son la interfaz principal durante el TeleOp.

🎮

Lectura de joysticks

double drive = -gamepad1.left_stick_y; double turn = gamepad1.right_stick_x; double strafe = gamepad1.left_stick_x;

Los valores van de -1.0 a 1.0. El eje Y suele invertirse.

🔘

Botones y gatillos

if (gamepad1.a) { /* acción A */ } if (gamepad1.b) { /* acción B */ } double power = gamepad1.right_trigger; boolean bumper = gamepad1.left_bumper;
03

Hardware: Motores y Servos

Declaración y configuración en hardwareMap.

⚙️

Motores DC

private DcMotor leftMotor, rightMotor; @Override public void runOpMode() { leftMotor = hardwareMap.get(DcMotor.class, "left"); rightMotor = hardwareMap.get(DcMotor.class, "right"); // ... }
🔄

Servos

private Servo claw; claw = hardwareMap.get(Servo.class, "claw"); // Posición: 0.0 (cerrado) a 1.0 (abierto) claw.setPosition(0.5);
04

Encoders y Movimiento Preciso

Los encoders permiten medir distancia y velocidad con precisión.

📏

Configuración básica

leftMotor.setMode(DcMotor.RunMode.STOP_AND_RESET_ENCODER); leftMotor.setMode(DcMotor.RunMode.RUN_USING_ENCODER); leftMotor.setTargetPosition(1000); leftMotor.setPower(0.5);
🧮

Cálculo de ticks por pulgada

Necesitas conocer:

  • Ticks por revolución del motor (ej. 537.7 para goBILDA 312 RPM).
  • Relación de engranajes.
  • Diámetro de la rueda.
// Ejemplo: 537.7 ticks/rev, rueda 96mm double TICKS_PER_INCH = 537.7 / (96 * Math.PI / 25.4);
05

Tu primer Autónomo

Combina encoders e IMU para mover el robot en una trayectoria simple.

🤖

Estructura de un autónomo

@Autonomous(name = "MiAutonomo") public class MiAutonomo extends LinearOpMode { @Override public void runOpMode() { initHardware(); waitForStart(); driveForward(24); // 24 pulgadas turnTo(90); // 90 grados driveForward(12); stopMotors(); } }
🧭

Giro con IMU

IMU imu = hardwareMap.get(IMU.class, "imu"); imu.resetYaw(); while (opModeIsActive() && imu.getRobotYawPitchRollAngles() .getYaw(AngleUnit.DEGREES) < 90) { leftMotor.setPower(0.3); rightMotor.setPower(-0.3); } leftMotor.setPower(0); rightMotor.setPower(0);
06

Siguiente paso: Road Runner

Cuando domines el autónomo básico, Road Runner te permitirá planificar trayectorias suaves y precisas.

🏗️

¿Qué es Road Runner?

Es una librería de código abierto para FTC que implementa planificación de trayectorias (motion profiling) y seguimiento de trayectorias (path following).

  • Trayectorias suaves con curvas de Bézier.
  • Control PID para cada rueda.
  • Soporte para odometría de 2 o 3 ruedas.
