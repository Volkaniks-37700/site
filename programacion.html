Programación FTC con Java

Esta guía está diseñada para el área de programación del equipo Volkaniks 37700. Encontrarás desde los conceptos fundamentales de OpModes hasta la configuración del Control Hub, programación de llantas mecanum y tu primer autónomo.

01

Estructura de un OpMode

En FTC existen dos tipos de OpModes: LinearOpMode y OpMode. Ambos controlan el robot, pero funcionan de manera diferente.

📏

LinearOpMode Secuencial

El robot ejecuta las instrucciones línea por línea, de arriba hacia abajo. Es ideal para autónomos porque el flujo es fácil de seguir.

@Autonomous(name = "MiAutonomo") public class MiAutonomo extends LinearOpMode { @Override public void runOpMode() { // Inicialización initHardware(); waitForStart(); // Espera el START // Se ejecuta secuencialmente driveForward(0.5, 2000); // 2 seg turnRight(0.5, 1000); // 1 seg stopMotors(); } }

📖 Doc oficial: Crear un OpMode →

🔄

OpMode Usamos este

Es un modelo iterativo: el método loop() se repite continuamente hasta que el robot se detiene. Es el que nuestro equipo utiliza actualmente.

@TeleOp(name = "MiTeleOp") public class MiTeleOp extends OpMode { @Override public void init() { // Se ejecuta una vez al presionar INIT initHardware(); } @Override public void init_loop() { // Se repite mientras espera START } @Override public void start() { // Se ejecuta una vez al presionar START } @Override public void loop() { // Se repite continuamente readGamepad(); updateMotors(); } @Override public void stop() { // Se ejecuta al detener el robot } }

Comparativa rápida

CaracterísticaLinearOpModeOpMode (Iterativo)
FlujoSecuencial (línea por línea)Iterativo (loop continuo)
Método principalrunOpMode()init(), loop(), start(), stop()

02

Control Hub y Driver Station

El Control Hub es el cerebro del robot. La Driver Station es el control remoto. Aquí aprenderás a configurarlos y a subir tu código.

🧠

¿Qué es el Control Hub?

Es el dispositivo que ejecuta tu código. Contiene el Robot Controller (la app que corre tus OpModes) y todos los puertos donde se conectan motores, servos y sensores.

  • Puertos de motor: 0 a 3 (integrados) + expansión.
  • Puertos de servo: 0 a 5 (integrados) + expansión.
  • Puertos I2C: Para sensores de color, distancia, IMU, etc.
  • Puerto USB: Para cámaras o dispositivos externos.
📱

¿Qué es la Driver Station?

Es el dispositivo desde el que controlas el robot. Generalmente es un Driver Hub o un celular Android con la app de Driver Station.

  • Se conecta por Wi-Fi al Control Hub.
  • Desde aquí seleccionas el OpMode a ejecutar.
  • Desde aquí configuras los puertos de cada motor y servo.
  • Muestra la telemetría en tiempo real.

🔌 Cómo configurar los puertos desde la Driver Station

1️⃣

Paso 1: Conectar el Driver Station

Enciende el Control Hub y conecta la Driver Station a su red Wi-Fi. Abre la app de Driver Station.

2️⃣

Paso 2: Abrir la configuración

En la Driver Station, toca los tres puntos verticales en la esquina superior derecha y selecciona "Configure Robot".

3️⃣

Paso 3: Crear o editar una configuración

Selecciona una configuración existente o crea una nueva. Aquí verás los puertos disponibles.

4️⃣

Paso 4: Asignar nombres y puertos

Para cada motor o servo, asigna un nombre (ej. "leftFront") y selecciona el puerto donde está conectado. Este nombre es el que usarás en tu código con hardwareMap.

⬆️ Cómo subir tu código al Control Hub

🖥️

Opción 1: Android Studio (recomendado)

Conecta el Control Hub a tu computadora por USB. En Android Studio, selecciona Build → Make Project y luego Run → Run 'TeamCode'. El código se compila y se instala automáticamente en el Control Hub.

📶

Opción 2: OnBot Java (inalámbrico)

Conéctate a la red Wi-Fi del Control Hub y abre un navegador en 192.168.43.1:8080. Desde ahí puedes escribir y compilar código directamente en el Control Hub, sin necesidad de Android Studio.

03

Llantas Mecanum

Nuestro robot usa llantas mecanum en las 4 ruedas. Esto permite movimiento omnidireccional: avanzar, retroceder, girar y desplazarse lateralmente sin cambiar la orientación del robot.

Cómo funcionan

Cada llanta tiene rodillos en un ángulo de 45 grados. Al combinar la dirección y velocidad de las 4 ruedas, el robot se mueve en cualquier dirección. Es lo que se conoce como "holonomic drive".

  • ↔️
    Strafe (desplazamiento lateral)Moverse de lado sin girar.
  • ↕️
    Avance y retrocesoMovimiento frontal y trasero normal.
  • 🔄
    RotaciónGirar sobre el propio eje.

💻 Código para Mecanum Drive

@TeleOp(name = "MecanumDrive") public class MecanumDrive extends OpMode { private DcMotor leftFront, rightFront, leftBack, rightBack; @Override public void init() { leftFront = hardwareMap.get(DcMotor.class, "leftFront"); rightFront = hardwareMap.get(DcMotor.class, "rightFront"); leftBack = hardwareMap.get(DcMotor.class, "leftBack"); rightBack = hardwareMap.get(DcMotor.class, "rightBack"); leftFront.setDirection(DcMotor.Direction.REVERSE); leftBack.setDirection(DcMotor.Direction.REVERSE); } @Override public void loop() { double forward = -gamepad1.left_stick_y; double strafe = gamepad1.left_stick_x; double rotate = gamepad1.right_stick_x; leftFront.setPower(forward + strafe + rotate); rightFront.setPower(forward - strafe - rotate); leftBack.setPower(forward - strafe + rotate); rightBack.setPower(forward + strafe - rotate); } }

04

Tu primer Autónomo

Un autónomo básico no necesita encoders ni sensores. Puedes hacer que el robot se mueva usando tiempos. Es la forma más rápida de empezar.

⏱️
Autónomo por tiempos

Le decimos al robot: "avanza a 0.5 de potencia durante 2 segundos, luego gira a 0.3 durante 1 segundo, luego detente". Es simple y funciona para empezar.

@Autonomous(name = "AutonomoPorTiempos") public class AutonomoPorTiempos extends OpMode { private DcMotor leftFront, rightFront, leftBack, rightBack; private ElapsedTime timer = new ElapsedTime(); @Override public void init() { leftFront = hardwareMap.get(DcMotor.class, "leftFront"); rightFront = hardwareMap.get(DcMotor.class, "rightFront"); leftBack = hardwareMap.get(DcMotor.class, "leftBack"); rightBack = hardwareMap.get(DcMotor.class, "rightBack"); leftFront.setDirection(DcMotor.Direction.REVERSE); leftBack.setDirection(DcMotor.Direction.REVERSE); } @Override public void loop() { waitForStart(); // Espera START // Fase 1: Avanzar 2 segundos timer.reset(); while (opModeIsActive() && timer.seconds() < 2.0) { setMotors(0.5, 0.5, 0.5, 0.5); } // Fase 2: Girar a la derecha 1 segundo timer.reset(); while (opModeIsActive() && timer.seconds() < 1.0) { setMotors(0.5, -0.5, 0.5, -0.5); } // Fase 3: Detenerse setMotors(0, 0, 0, 0); } private void setMotors(double lf, double rf, double lb, double rb) { leftFront.setPower(lf); rightFront.setPower(rf); leftBack.setPower(lb); rightBack.setPower(rb); } }
